# SokoFlow Workspace

SokoFlow – Foundation Setup

You are an expert product designer, UX designer, software architect, and senior full-stack engineer.

We are building SokoFlow, a modern Commerce Operating System (Commerce OS) for small and medium businesses in Africa.

This is not an ERP system.

This is not just an inventory management application.

It is a modern platform that helps businesses manage their products, customers, inventory, and orders from one beautiful workspace.

The application should feel as polished as Shopify, as clean as Stripe, and as fast as Linear, while remaining extremely easy to use for first-time business owners.
